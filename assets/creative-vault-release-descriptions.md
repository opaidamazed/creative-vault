## Publishing checklist

- Create a separate GitHub Release for each library or resource pack.
- Use the suggested tag, or increase the version when publishing an updated archive (for example, `animated-backgrounds-v2`).
- Attach the matching ZIP file in the **Attach binaries** area.
- Publish the release.
- Copy the direct URL of the ZIP asset and paste it into the matching resource's Download URL field in the Creative Vault admin dashboard.
- Test the download link before replacing an existing working link.

**Note:** Update file counts, archive sizes, and ZIP filenames to match the final archive before publishing. The Animated Backgrounds and Icons Pack sections intentionally leave their file counts and archive sizes as placeholders.
